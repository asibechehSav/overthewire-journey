# Bandit Level 2

## Goal
Find the password for the next level in a file called -

## Commands I used
- ssh 
- ls
- cat 

## What I learned
- Typing just cat - the terminal thinks the dash is an instruction, not a file name.
- So i told the terminal this is a path not an option by adding ./ in front of the name.
- The ./ means in the current folder
